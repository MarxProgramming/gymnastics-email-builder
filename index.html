?Use your script in Google Sheets＋
  1. Set up the headings.

    Put these in row 1, in any column order. Other columns can stay.

    Childs NameParents NameEmailEmail StatusReview
  2. Paste your script.

    Open Extensions → Apps Script in your sheet. In a new project, replace the starter code with your copied script, save, then reload the sheet. Use one club script per project; take care to preserve any existing scripts.

  3. Select your rows and send.

    Highlight the rows you want, then choose your club’s email menu → Send selected emails. It sends straight away, one row at a time, and marks each result in Email Status. Google may ask you to authorise the script the first time.

A few helpful details

Use Check selected rows (no email) to count eligible rows first. Rows with anything in Email Status or Review are skipped, as are hidden and filtered rows. Google filter views are not detected. Siblings sharing an address each get their own email.

For a new message, use a fresh sheet or deliberately clear only the statuses you want to reuse. If a send is interrupted or an error appears, check Sent mail before clearing its status. If Google’s allowance or the time limit is reached, select the same rows later to continue.

Emails come from the Google account running the script. Use the appropriate club account.
